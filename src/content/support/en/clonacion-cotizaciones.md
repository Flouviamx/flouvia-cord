If you frequently send similar proposals to different prospects (e.g. software renewals or standard packages), it is not necessary to create each quote from scratch.

### How to clone a quote?

1. Go to **Quotes** and open the quote you want to duplicate (draft, sent, approved, or even rejected — any status can be cloned).
2. On the detail screen, click **Duplicate quote**.
3. A new draft is generated with a new folio number, a fresh 30-day validity period, and its own public link, and Cord takes you to its detail page.
4. Use **Continue editing** to open it in the editor, adjust what you need, and send it. See [Create a quote or an invoice step by step](/en/support/crear-cotizacion-o-factura).

The duplicated draft counts toward your plan's active-quote limit.

**What IS copied:**
- The assigned client (the clone is addressed to the same client; you can change it before sending).
- All line items, with their description, quantity, list price, final price, cost, and tax rate. If a line's rate is no longer in your tax catalog, the clone uses the default rate; review it before sending.
- The original quote's payment terms, notes, sale currency, whether prices include tax, deposit, and recurring charge.

**What is NOT copied:**
- The exchange rate: if the quote is in another currency, the clone locks the rate of the day you create it.
- The event history, signatures, comments, or payments. Each clone is a completely clean slate; the only new entry is an event noting which quote it was duplicated from.

**Duplicate or create a new version?** If only lines or prices change for the same client, use **Modify and resend**: the client sees the new version at the same link. A new version restarts the validity with the same length. Duplicate when you need a different client, currency or terms, including a different validity length.

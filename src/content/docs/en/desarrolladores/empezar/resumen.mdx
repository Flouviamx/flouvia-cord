Cord's API is resource-oriented, responds with JSON and standard HTTP status codes, and is available on every plan. Every response carries a `Cord-Request-Id`, every write accepts `Idempotency-Key`, and every key is pinned to an API version. Start with the [Quickstart](/en/docs/desarrolladores/empezar/inicio-rapido): in five minutes you create a quote and receive its webhook on your machine.

## What you can build

- **Sync your ERP or CRM:** keep your catalog and clients up to date with the [Products API](/en/docs/desarrolladores/funciones/productos) and the [Clients API](/en/docs/desarrolladores/funciones/clientes).
- **React to events:** mark an order as paid when `quote.paid` arrives by [webhook](/en/docs/desarrolladores/herramientas/webhooks), or reconcile with the [event history](/en/docs/desarrolladores/funciones/eventos).
- **Invoice from your system:** create, issue and collect invoices with the [Invoices API](/en/docs/desarrolladores/funciones/facturas).
- **Connect AI agents:** give Claude or ChatGPT access to your data with the [MCP server](/en/docs/desarrolladores/herramientas/mcp), or let them propose an account's setup with [assisted setup](/en/docs/desarrolladores/herramientas/configuracion-asistida).
- **Embed the close in your product:** quote, invoice and tax form with [Cord Elements](/en/docs/desarrolladores/herramientas/elements/resumen).
- **Ship an app for many businesses:** connect it with [OAuth](/en/docs/desarrolladores/herramientas/oauth) instead of asking for keys.

## SDKs and tools

| Tool | Install | What for |
|---|---|---|
| [v1 REST API](/en/docs/desarrolladores/referencia) | — | `https://cordhq.app/api/v1`, with any HTTP client. |
| [Node SDK](/en/docs/desarrolladores/herramientas/sdks) | `npm install @flouviahq/node` | The full API from your server, with retries, idempotency and webhook verification. Node, Bun, Deno and edge. |
| [Cord Elements](/en/docs/desarrolladores/herramientas/elements/resumen) | `npm install @flouviahq/elements` | Quote, invoice and tax form in the browser: React, Vue, Web Components and headless. |
| [CLI](/en/docs/desarrolladores/herramientas/cli) | `npx @flouviahq/cli` | Browser sign-in, AI setup, project integration and webhooks on your `localhost`. |
| [MCP server](/en/docs/desarrolladores/herramientas/mcp) | — | Tools for AI agents over your data. |
| [Cord Workbench](/en/docs/desarrolladores/herramientas/workbench) | — | Keys, endpoints, events and the log of every request, inside the app. |
| Python and PHP | — | **Not published yet.** Use the REST API directly. |

## Test environments

Every account has an isolated test environment: what you create with an `sk_test_` key or with the app's test mode doesn't touch your real data. With a test key you get simulators to trigger stamping, expirations and webhooks, and `cord listen` to receive them on your machine. The exception is [assisted setup](/en/docs/desarrolladores/herramientas/configuracion-asistida) proposals, which always go to your real account and are only applied if a person approves them. See [Test environments](/en/docs/desarrolladores/empezar/pruebas).

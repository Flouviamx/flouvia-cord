## What it is

Tasks are a lightweight to-do list for your organization. They show in the **Tasks and
reminders** widget on [Home](/en/docs/gestion/dashboard), ordered by due date. A task
can be linked to a quote; in that case it shows the quote number.

<DmTasksWidget lang="en" />

## Requirements

- **Permission:** Quotes, Collections, or Clients (any of the three) to create, complete, or delete.
- **Plan:** all.
- **Who sees them:** every member who sees Home. A task isn't assigned to a person.

## Create a task

<Steps>
1. **From any screen:** click **Create** in the top bar and choose **Task**. Or, on Home, use the field in the **Tasks and reminders** widget.
2. Type the description, for example "Call Luis to ask whether he reviewed the quote". Up to 200 characters.
3. Optional: choose the **Due date**.
4. Click **Add** (or **Create**, depending on where you opened it).
</Steps>

Tasks you create from the app aren't linked to a quote. Those created by a workflow,
the API, or MCP can be.

## Follow-up

- The widget lists up to 12 pending tasks, nearest due date first; tasks without a date go last.
- When the due date has passed, the task carries the red **overdue** label.
- Check the box to complete it: it leaves the pending list.
- The **×** button deletes it entirely.

<Callout type="warning">
**Cord doesn't send task reminders.** When the due date arrives you get no email or
alert: the task is only marked overdue in the widget. Check your Home often.
</Callout>

## Tasks Cord creates for you

When a payment operation needs your attention, Cord adds the task:

- **Chargeback response** (titled "Responder contracargo" with the amount): when a client disputes a card charge, with the deadline to submit evidence as the due date (see [Disputes](/en/docs/pagos/disputas)).
- **SPEI refund transfer** (titled "Transferir reembolso SPEI" with the amount): when you request a refund of a SPEI payment, which is transferred outside Cord, linked to the quote (see [Refunds](/en/docs/pagos/reembolsos)).

## Other ways to create tasks

<Tabs>
<TabItem label="Workflows">

The **Create a task** action in [Workflows](/en/docs/automatizacion/workflows/acciones)
adds a task with a title (it can use event data, such as the quote number or client)
and, optionally, **Due in (days)**, up to 365. If the event is about a quote, the task
is linked to it. Example: "when the client rejects a quote, create a task to call them
tomorrow".

</TabItem>
<TabItem label="API">

`POST /api/v1/tareas` creates a task with `titulo`, an optional `due_date`
(YYYY-MM-DD), and an optional `cotizacion_id`. It requires a key with write permission.
The API creates tasks; completing and deleting them is done in the app. See [Tasks
API](/en/docs/desarrolladores/funciones/tareas).

</TabItem>
<TabItem label="MCP">

The **crear_tarea** tool in the [MCP server](/en/docs/desarrolladores/herramientas/mcp)
lets an AI assistant create a follow-up task, optionally linked to a quote and with a date.

</TabItem>
</Tabs>

## Task events

Each task emits events you can use in [workflows](/en/docs/automatizacion/workflows/disparadores)
and [webhooks](/en/docs/desarrolladores/herramientas/webhooks):

| Event | When |
|---|---|
| **A task is created** | When it's created from the app, a workflow, the API, or MCP. |
| **A task is completed** | When it's marked complete. |

Deleting a task emits no event.

## Limits by plan

Tasks have no cap by plan.

## Common problems

**I don't see the tasks widget.** You hid it when customizing Home: bring it back from the **Library**.

**I can't add a task.** Your role doesn't have the Quotes, Collections, or Clients permission.

**A task is missing from the list.** The widget shows 12 pending tasks; complete or delete the ones that no longer apply.

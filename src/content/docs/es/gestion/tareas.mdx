## Qué es

Las tareas son una lista ligera de pendientes de tu organización. Se ven en el widget
**Tareas y recordatorios** del [Inicio](/docs/gestion/dashboard), ordenadas por fecha
límite. Una tarea puede estar ligada a una cotización; en ese caso muestra su folio.

<DmTasksWidget lang="es" />

## Requisitos

- **Permiso:** Cotizaciones, Cobranza o Clientes (cualquiera de los tres) para crear, completar o eliminar.
- **Plan:** todos.
- **Quién las ve:** todos los miembros que ven el Inicio. Una tarea no se asigna a una persona.

## Crea una tarea

<Steps>
1. **Desde cualquier pantalla:** pulsa **Crear** en la barra superior y elige **Tarea**. O, en el Inicio, usa el campo del widget **Tareas y recordatorios**.
2. Escribe la descripción, por ejemplo "Llamar a Luis para preguntar si ya revisó la cotización". Admite hasta 200 caracteres.
3. Opcional: elige la **Fecha límite**.
4. Pulsa **Agregar** (o **Crear**, según dónde la abriste).
</Steps>

Las tareas que creas desde la app no se ligan a una cotización. Las que crean un
workflow, la API o el MCP sí pueden quedar ligadas.

## Seguimiento

- El widget lista hasta 12 tareas pendientes, la de fecha más próxima primero; las que no tienen fecha van al final.
- Cuando la fecha límite ya pasó, la tarea lleva la etiqueta **vencida** en rojo.
- Marca la casilla para completarla: sale de la lista de pendientes.
- El botón **×** la elimina por completo.

<Callout type="warning">
**Cord no envía recordatorios de tareas.** Al llegar la fecha límite no recibes correo
ni aviso: la tarea solo se marca como vencida en el widget. Revisa tu Inicio con
frecuencia.
</Callout>

## Tareas que Cord crea por ti

Cuando una operación de cobro necesita tu intervención, Cord agrega la tarea:

- **Responder contracargo:** cuando un cliente disputa un cargo con tarjeta, con el monto y, como fecha límite, el plazo para enviar evidencia (ver [Disputas](/docs/pagos/disputas)).
- **Transferir reembolso SPEI:** cuando solicitas el reembolso de un cobro por SPEI, que se transfiere por fuera, ligada a la cotización (ver [Reembolsos](/docs/pagos/reembolsos)).

## Otras formas de crear tareas

<Tabs>
<TabItem label="Workflows">

La acción **Crear una tarea** de [Workflows](/docs/automatizacion/workflows/acciones)
agrega una tarea con un título (puede usar datos del evento, como el folio o el cliente)
y, opcionalmente, **Vence en (días)**, hasta 365. Si el evento es de una cotización, la
tarea queda ligada a ella. Ejemplo: "cuando el cliente rechace una cotización, crea una
tarea para llamarle mañana".

</TabItem>
<TabItem label="API">

`POST /api/v1/tareas` crea una tarea con `titulo`, `due_date` opcional (AAAA-MM-DD) y
`cotizacion_id` opcional. Requiere una llave con permiso de escritura. La API crea
tareas; completarlas y eliminarlas se hace desde la app. Ver [API de
tareas](/docs/desarrolladores/funciones/tareas).

</TabItem>
<TabItem label="MCP">

La herramienta **crear_tarea** del [servidor MCP](/docs/desarrolladores/herramientas/mcp)
permite que un asistente de IA cree una tarea de seguimiento, opcionalmente ligada a
una cotización y con fecha.

</TabItem>
</Tabs>

## Eventos de las tareas

Cada tarea emite eventos que puedes usar en [workflows](/docs/automatizacion/workflows/disparadores)
y [webhooks](/docs/desarrolladores/herramientas/webhooks):

| Evento | Cuándo |
|---|---|
| **Se crea una tarea** | Al crearla desde la app, un workflow, la API o el MCP. |
| **Se completa una tarea** | Al marcarla como completada. |

Eliminar una tarea no emite evento.

## Límites por plan

Las tareas no tienen tope por plan.

## Problemas comunes

**No veo el widget de tareas.** Lo ocultaste al personalizar el Inicio: recupéralo desde la **Biblioteca**.

**No puedo agregar una tarea.** Tu rol no tiene los permisos Cotizaciones, Cobranza ni Clientes.

**Falta una tarea en la lista.** El widget muestra 12 pendientes; completa o elimina las que ya no aplican.

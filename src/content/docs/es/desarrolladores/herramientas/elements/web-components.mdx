## Web Component (Vanilla JS, PHP, Rails)

Si no utilizas React ni Vue, o estás integrando Cord en un sitio renderizado en el servidor (como Laravel, Django, o WordPress), puedes utilizar el Web Component estándar `<cord-quote>` (`<cord-cotizador>` sigue funcionando como alias).

Este componente está compilado bajo los estándares de la plataforma web, lo que significa que el navegador lo entiende de forma nativa sin necesidad de un bundler.

```html
<!-- Importar el módulo ES -->
<script type="module" src="https://unpkg.com/@flouviahq/elements/dist/index.mjs"></script>

<!-- Renderizar el componente nativo -->
<div style="height: 800px;">
  <cord-quote
    token="9f3b6c2a7e1d4f8b0a5c3e7d1b9f2a46"
    min-height="500">
  </cord-quote>
</div>

<script>
  // Escuchar eventos estándar del DOM
  const cotizador = document.querySelector('cord-quote');

  cotizador.addEventListener('approved', (e) => {
    console.log('Aprobada por', e.detail.signed_by);
  });
</script>
```

<Callout type="info">
**Nota de Eventos:** Al usar el Web Component nativo, los eventos llegan **sin** el prefijo `cord:`. Es decir, en lugar de escuchar `cord:approved`, escucharás simplemente `approved` como cualquier otro evento de la API del DOM.
</Callout>

## La factura: `<cord-invoice>`

`<cord-invoice>` muestra una factura de Cord (la de `/i/{token}`) en tu sitio: saldo pendiente, estado, partidas, totales y la descarga del PDF. El token es el de la factura hospedada, el mismo que va en el correo que recibe tu cliente.

```html
<cord-invoice token="TOKEN_DE_LA_FACTURA"></cord-invoice>

<script>
  document.querySelector('cord-invoice').addEventListener('paid', (e) => {
    console.log('Factura pagada', e.detail.folio);
  });
</script>
```

El botón de pago abre la factura hospedada en una ventana de Cord: los datos de pago nunca se capturan dentro del iframe. Mientras la factura sigue abierta, el embed consulta su saldo y emite `status_changed` cuando cambia y `paid` cuando queda saldada. Con `embed.js`, agrega `data-cord-document="invoice"` al `div`. Igual que la cotización, sin dominios permitidos en **Ajustes › Cotizador embebible** los eventos llegan sin datos.

`theme`, `variables` y `fonts` del [Appearance API](/docs/desarrolladores/herramientas/elements/apariencia) aplican a la factura; `rules` y `layout` son del cotizador.

## Estado en vivo: `state` y `statechange`

`<cord-quote>` y `<cord-invoice>` reducen los eventos del iframe a un estado que puedes leer en cualquier momento con la propiedad `state`, y emiten `statechange` cada vez que cambia. Así dibujas tu propio resumen sin escuchar evento por evento.

```html
<cord-quote token="9f3b6c2a7e1d4f8b0a5c3e7d1b9f2a46"></cord-quote>
<p id="resumen"></p>

<script type="module">
  const quote = document.querySelector('cord-quote');
  const resumen = document.querySelector('#resumen');

  quote.addEventListener('statechange', (e) => {
    const s = e.detail; // igual a quote.state
    if (!s.ready) return;
    const total = s.total === null ? '' : new Intl.NumberFormat('es-MX', { style: 'currency', currency: s.moneda }).format(s.total);
    resumen.textContent = `${s.folio ?? ''} ${s.status ?? ''} ${total}`;
    if (s.paid) resumen.textContent += ' · pagada';
  });
</script>
```

| Campo | Contenido |
|---|---|
| `ready` | El cotizador terminó de dibujarse. |
| `status` | `sent`, `viewed`, `approved`, `rejected`, `paid`, `expired`… |
| `folio`, `moneda`, `total` | Del documento. El total viaja siempre con su divisa. |
| `approved`, `rejected`, `paid` | Atajos booleanos. `paid` también es verdadero para una cotización ya facturada. |
| `signedBy` | Quién aprobó, si aprobó en esta sesión. |
| `lastEvent` | El último evento recibido, por ejemplo `cord:approved`. |

Sin dominios permitidos en **Ajustes › Cotizador embebible**, los eventos llegan sin datos y `status`, `folio`, `moneda` y `total` se quedan en `null`. En React es `onStateChange` en `<CordCotizador>`; en Vue, el evento `@state`.

## Estilos: `::part`

Los dos elementos viven en un Shadow DOM: tus estilos no los rompen y los suyos no tocan tu página. Para personalizarlos desde afuera:

```css
cord-quote::part(frame) {
  border-radius: 24px;
  box-shadow: 0 12px 40px rgba(10, 25, 47, 0.08);
}

cord-quote::part(skeleton) {
  border-radius: 24px;
}
```

| Parte | Elemento |
|---|---|
| `root` | El contenedor del elemento. |
| `skeleton` | El marcador de carga que se ve mientras llega el documento. |
| `frame` | El `<iframe>` con el documento de Cord. |

El contenido de adentro del iframe se personaliza con el [Appearance API](/docs/desarrolladores/herramientas/elements/apariencia) (atributo `appearance` como JSON, o la propiedad `appearance` como objeto), no con CSS de tu página.

| Atributo | Detalle |
|---|---|
| `token` | **Obligatorio.** El token público del documento. |
| `appearance` | Appearance como JSON. |
| `min-height` | Alto mínimo del iframe en píxeles (420 por defecto). |
| `base-url` | Origen de Cord, si usas un dominio propio. |
| `debug` | Activa la barra de depuración (ver [Eventos](/docs/desarrolladores/herramientas/elements/eventos#barra-de-depuración)). |

## Vue y Nuxt

El SDK de Cord provee un envoltorio nativo (wrapper) para Vue 3 que maneja la reactividad y los eventos utilizando el paradigma de Vue (`@` o `v-on`).

### Instalación

```bash
npm install @flouviahq/elements
```

### Uso

Importa el componente `<CordCotizador>` desde el entrypoint `/vue` y pásalo a tu template.

```vue
<script setup>
import { CordCotizador } from '@flouviahq/elements/vue';
import { ref } from 'vue';

const miToken = ref('9f3b6c2a7e1d4f8b0a5c3e7d1b9f2a46');

function handleApproved(detail) {
  console.log('El cliente firmó:', detail.signed_by);
}

function handlePay(detail) {
  window.location.href = detail.url;
}
</script>

<template>
  <main class="cotizacion-container">
    <CordCotizador
      :token="miToken"
      @approved="handleApproved"
      @pay="handlePay"
    />
  </main>
</template>
```

## Framer

Si estás construyendo tu sitio web en **Framer**, puedes agregar Cord Elements como un *Code Component* arrastrable y soltable.

Crea un nuevo componente de código en Framer y pega lo siguiente:

```tsx
import { FramerCordCotizador } from '@flouviahq/elements/framer';
export default FramerCordCotizador;
```

Esto registrará los controles de propiedades en la interfaz visual de Framer (Property Controls), exponiendo el campo `Token` en el panel derecho para que tus diseñadores puedan modificarlo visualmente sin tocar código.

## Webflow

A diferencia de Framer (un Code Component real), Webflow no ejecuta componentes de React —
por eso el SDK expone un entrypoint separado (`@flouviahq/elements/webflow`) pensado para el
editor visual de Webflow: un script de auto-inicialización que **no requiere escribir código**,
solo atributos personalizados.

1. En Webflow, agrega un **Div Block** donde quieras que aparezca el cotizador.
2. En el panel de **Settings** del elemento, agrega un **Custom Attribute**: `data-cord-token`
   con el token de tu cotización como valor. (Opcionalmente, `data-cord-base-url` si usas un
   dominio propio, y `data-cord-min-height` para el alto mínimo del iframe.)
3. En **Page Settings › Custom Code** (o en los ajustes del sitio si quieres que aplique a
   todas las páginas), agrega este script antes de `</body>`:

```html
<script src="https://unpkg.com/@flouviahq/elements/dist/webflow.js"></script>
```

El script busca automáticamente todos los elementos con `data-cord-token` en la página (al
cargar, y de nuevo si Webflow los agrega después) y monta el cotizador ahí — no expone eventos
JS propios como el Web Component nativo; para eso, usa `<cord-cotizador>` directamente o el
Code Component de Framer.

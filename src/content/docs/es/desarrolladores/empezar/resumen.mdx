  <p class="page-subtitle">Integra Cord con tus sistemas: API REST, webhooks, SDK de Node, CLI, servidor MCP y Cord Elements.</p>
</header>

La API de Cord está orientada a recursos, responde JSON con códigos HTTP estándar y está disponible en todos los planes. Cada respuesta trae un `Cord-Request-Id`, cada escritura acepta `Idempotency-Key` y cada llave queda fijada a una versión de la API. Empieza por el [Inicio rápido](/docs/desarrolladores/empezar/inicio-rapido): en cinco minutos creas una cotización y recibes su webhook en tu máquina.

## Qué puedes construir

- **Sincronizar tu ERP o tu CRM:** mantén catálogo y clientes al día con la [API de Productos](/docs/desarrolladores/funciones/productos) y la [API de Clientes](/docs/desarrolladores/funciones/clientes).
- **Reaccionar a eventos:** marca un pedido como pagado cuando llegue `quote.paid` por [webhook](/docs/desarrolladores/herramientas/webhooks), o reconcilia con el [historial de eventos](/docs/desarrolladores/funciones/eventos).
- **Facturar desde tu sistema:** crea, emite y cobra facturas con la [API de Facturas](/docs/desarrolladores/funciones/facturas).
- **Conectar agentes de IA:** dale a Claude o a ChatGPT acceso a tus datos con el [servidor MCP](/docs/desarrolladores/herramientas/mcp), o deja que propongan la configuración de una cuenta con la [configuración asistida](/docs/desarrolladores/herramientas/configuracion-asistida).
- **Embeber el cierre en tu producto:** cotizador, factura y formulario fiscal con [Cord Elements](/docs/desarrolladores/herramientas/elements/resumen).
- **Publicar una app para muchos negocios:** conéctala con [OAuth](/docs/desarrolladores/herramientas/oauth) en lugar de pedir llaves.

## SDKs y herramientas

| Herramienta | Instala | Para qué |
|---|---|---|
| [API REST v1](/docs/desarrolladores/referencia) | — | `https://cordhq.app/api/v1`, con cualquier cliente HTTP. |
| [SDK de Node](/docs/desarrolladores/herramientas/sdks) | `npm install @flouviahq/node` | La API completa desde tu servidor, con reintentos, idempotencia y verificación de webhooks. Node, Bun, Deno y edge. |
| [Cord Elements](/docs/desarrolladores/herramientas/elements/resumen) | `npm install @flouviahq/elements` | Cotizador, factura y formulario fiscal en el navegador: React, Vue, Web Components y headless. |
| [CLI](/docs/desarrolladores/herramientas/cli) | `npx @flouviahq/cli` | Login desde el navegador, configuración con IA, integración del proyecto y webhooks en tu `localhost`. |
| [Servidor MCP](/docs/desarrolladores/herramientas/mcp) | — | Herramientas para agentes de IA sobre tus datos. |
| [Cord Workbench](/docs/desarrolladores/herramientas/workbench) | — | Llaves, endpoints, eventos y el registro de cada petición, dentro de la app. |
| Python y PHP | — | **Aún no publicados.** Usa la API REST directamente. |

## Entornos de prueba

Cada cuenta tiene un entorno de prueba aislado: lo que creas con una llave `sk_test_` o con el modo prueba de la app no toca tus datos reales. Con una llave de prueba tienes simuladores para provocar timbrados, vencimientos y webhooks, y `cord listen` para recibirlos en tu máquina. La excepción son las propuestas de [configuración asistida](/docs/desarrolladores/herramientas/configuracion-asistida), que siempre van a tu cuenta real y solo se aplican si una persona las aprueba. Ver [Entornos de prueba](/docs/desarrolladores/empezar/pruebas).

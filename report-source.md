## Incidencia de remitente

Gmail aceptó el parámetro solicitado para `hola@cordhq.app`, pero la cabecera real de los mensajes iniciales fue `Flouvia <hola@flouvia.com>`. Se confirmó en Admin Console que `cordhq.app` es un dominio secundario verificado con Gmail activo y se agregó `hola@cordhq.app` como alias del usuario `hola@flouvia.com`.

El alias fue verificado mediante el mensaje de confirmación recibido en `hola@cordhq.app`. Una prueba y el lote correctivo muestran la cabecera real `From: hola@cordhq.app`.
